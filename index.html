프로젝트 소개

건설·제조 현장 근로자가 안전 규정을 텍스트·음성·이미지로 즉시 검색하고, 관리자는 교육·점검 실적을 시스템화하여 기관 제출용 증빙으로 출력하는 통합 안전 관리 플랫폼을 구축합니다.

핵심 요구사항 분석

  • 모바일 앱(Android·iOS) — 안전 규정 열람, 텍스트·음성·이미지 복합 검색, 일일 점검 체크리스트, 사진 첨부
  • 관리자 웹(PC) — 대시보드, 안전 규정 CRUD, 교육 실적 관리, 점검 현황 조회, PDF 출력, 회원 관리
  • 음성 검색 — STT API 연동을 통해 인식된 텍스트로 키워드 매칭
  • 이미지 검색 — 카메라 촬영 사물 인식(Vision AI)을 통해 매칭 키워드 → 안전 규정 검색
  • HWP 안전 규정 데이터 → 텍스트 형태로 정기 수동 업데이트, 검색용 키워드(태그) 부여
  • 교육 이수·일일 점검 실적 PDF 출력 — 고용노동부 등 기관 점검 시 증빙 자료로 제출
  • FCM 기반 푸시 알림 — 점검 누락, 교육 일정, 신규 규정 등 운영 통지
  • 요구 기술 스택 — AWS, Express.js, FCM, MySQL, Node.js, React Native

제안 포인트

1. 현장 친화적 복합 검색 UX

현장 근로자는 장갑·먼지·소음 환경에 노출되어 정밀한 텍스트 입력이 어렵습니다. 음성 검색과 카메라 사물 인식 검색을 동등한 1차 진입 동선으로 배치하고, 검색 결과는 규정별 키워드 태그 매칭 점수 기반으로 우선순위를 정렬합니다.

2. HWP → 검색 가능 데이터 변환 파이프라인

관리자 웹에서 HWP 본문을 텍스트로 입력·수정하면 규정 본문 + 검색용 키워드(태그) 구조로 저장됩니다. 음성·이미지 검색 키워드와 동일한 인덱스를 공유하여 3가지 검색 방식이 일관된 결과를 반환하도록 설계합니다.

3. 기관 제출용 증빙 자동화

교육 이수 명단·교육 일지·일일 점검표를 단일 PDF 템플릿으로 출력합니다. 고용노동부 점검 시 즉시 제출 가능한 양식으로 설계하며, 기간·현장·사용자별 필터로 원하는 범위만 추출합니다.

4. 운영 친화적 인프라

AWS(EC2/RDS MySQL/S3) + Express.js + Firebase Cloud Messaging 구성으로 클라이언트 요구 기술 스택과 100% 일치합니다. 월 단위 호스팅·유지보수 계약을 위한 운영 매뉴얼·모니터링 설정·백업 정책을 함께 제공합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

건설·제조 현장 근로자는 복잡한 안전 규정을 즉시 참조하기 어렵습니다. 글로 된 규정집을 들고 다닐 수 없고, 텍스트 입력은 장갑·먼지·소음 환경에서 비효율적이며, 사물의 정확한 명칭을 모를 때는 검색 자체가 불가능합니다.

본 프로젝트는 (1) 텍스트·음성·이미지 3종 검색을 통한 직관적 안전 규정 접근, (2) 일일 안전 점검의 디지털화, (3) 관리자의 교육 이수·점검 실적 시스템화 및 기관 제출용 증빙 자동화를 통해 산업 현장 안전 관리 체계를 모바일 우선으로 전환하는 것을 목표로 합니다.

2. 사용자 정의

사용자 유형설명주요 기능
현장 근로자안전 규정을 검색·점검하는 일선 사용자모바일 앱 로그인, 규정 검색(텍스트/음성/이미지), 일일 점검 작성, 사진 첨부
현장 관리자본인 현장의 점검·교육 데이터를 관리하는 책임자관리자 웹 로그인, 점검 현황 조회, 교육 일지 등록, 회원 승인, PDF 출력
시스템 관리자안전 규정 데이터·전체 회원·통계를 관리하는 본사 운영자안전 규정 CRUD, 키워드 태그 관리, 회원 권한 설정, 전사 대시보드

3. 기능 요구사항

3.1 사용자 앱 (Android·iOS)

  • [필수] 이메일·비밀번호 회원가입 및 로그인 (현장별 승인 프로세스)
  • [필수] 안전 규정 열람 — 카테고리·태그·즐겨찾기 기반 탐색
  • [필수] 텍스트 검색 — 키워드·본문 매칭, 검색 이력
  • [필수] 음성 검색 — STT API 연동, 인식 결과 확인 후 검색
  • [필수] 카메라·이미지 검색 — 사물 인식 후 매칭 키워드 → 규정 검색
  • [필수] 일일 안전 점검 — 체크리스트, 현장 사진 첨부, 위치 정보 기록
  • [필수] 푸시 알림 (FCM) — 점검 미수행, 신규 규정, 교육 일정 통지

3.2 관리자 웹 (PC)

  • [필수] 대시보드 — 회원·점검·교육 현황 통계
  • [필수] 안전 규정 관리 — 본문 입력·수정, 카테고리 분류, 검색용 키워드 태그
  • [필수] 교육 실적 관리 — 오프라인 교육 일지, 이수자 명단 등록
  • [필수] 점검 현황 조회 — 일자·현장·사용자별 필터, 사진 미리보기
  • [필수] 문서 출력 — 교육 이수 내역·점검 실적 PDF 다운로드 (기관 제출용 증빙)
  • [필수] 회원 관리 — 가입 승인, 권한 설정(현장 관리자/근로자), 비활성화
